# My Skill

## Purpose

Provide a single triggerable skill that standardizes behavior in this repository and routes work through the preferred local skill style.

## Trigger Keywords

Use this skill when user input contains any of:

- `my_skill`
- `use my skill`
- `repo default skill`
- `caveman`
- `diagnose`
- `grill-me`
- `improve-codebase-architecture`
- `zoom-out`
- `使用 my_skill`
- `使用我的 skill`

## Required Behavior

1. Keep responses concise and implementation-oriented.
2. Prefer diagnosing root cause before proposing code changes.
3. When architecture tradeoffs appear, explain options and pick a clear default.
4. When user asks broad context, provide a zoomed-out map first, then specifics.
5. Preserve repository conventions and avoid unrelated edits.
